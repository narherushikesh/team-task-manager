# 🚀 Team Task Manager

A modern full-stack Team Task Manager web application built using React.js, Node.js, Express.js, MongoDB Atlas, and JWT Authentication.

---

# 📌 Features

✅ User Authentication  
✅ Create & Manage Tasks  
✅ Dashboard Analytics  
✅ Modern Responsive UI  
✅ MongoDB Database Integration  
✅ JWT Authentication  
✅ Full Stack Deployment on Vercel  

---

# 🛠️ Tech Stack

## Frontend
- React.js
- CSS
- Axios
- React Icons
- Recharts

## Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/narherushikesh/team-task-manager.git
```

---

# ▶️ Backend Setup

```bash
cd backend
npm install
npm run dev
```

Backend runs on:

```bash
http://localhost:5000
```

---

# ▶️ Frontend Setup

```bash
cd frontend
npm install
npm start
```

Frontend runs on:

```bash
http://localhost:3000
```
